# メタリョーシカ

> 観測したものが、次の観測対象になる。  
> メタな視線が自分自身を取り込みながら、外側へ増殖していく構造。

## メタリョーシカ【meta-ryoshka】〔名〕

ある発言・行動・作品・出来事などに対するメタな評価、解釈、観測、記録が、その評価・解釈・観測・記録自体を次の観測対象として取り込み、会話や記述が進むたびに外側へ新たなメタ層が付加されてゆく状態。また、そのような構造。

### 概念上の特徴

メタリョーシカは、単なる「入れ子構造」や「作中作」や「メタ発言」を指す言葉ではない。

あらかじめ何重にも仕込まれた構造を、外側から眺めるだけのものでもない。ある対象について行われた評価・説明・記録・予測が、次の瞬間には新たな対象として扱われ、その対象化への言及までもがさらに記録される。その結果、メタな観測が観測対象を消費するのではなく、観測行為そのものを次の層として取り込みながら、外側へ殻を増殖させてゆく。

マトリョーシカが、内側に同型の人形を抱え込む構造だとすれば、メタリョーシカでは、会話・記述・反応のたびに新しい外殻が後から形成される。

## メタ表現との違い

| 概念 | 主な特徴 |
| --- | --- |
| メタ表現 | 作品や発言が、自分自身またはその形式・成立条件に言及する |
| 入れ子構造 | 物語や構造が、あらかじめ複数の階層を含んでいる |
| メタリョーシカ | メタな評価・観測・記録が、その行為自体を次の観測対象に取り込み、会話の進行に応じて外側の層を増やしてゆく |

したがって、最初から三重構造として設計されたものが、必ずしもメタリョーシカになるわけではない。後から加わった観測や記録が、さらに観測され、記録され、予測されるという動的な累積が重要である。

## 典型的な連鎖

1. ある発言・行動・出来事が発生する。
2. それに対する評価や解釈が行われる。
3. 評価や解釈そのものが話題になる。
4. 「その評価を話題にしたこと」が記録・分析される。
5. その記録や分析が、次の観測対象として扱われる。
6. ついには、層が増殖している構造そのものが観測される。

この時点では、最初の発言を直接論じているのか、最初の発言についての評価を論じているのか、その評価を論じた記録を論じているのかが曖昧になる。曖昧になったこと自体も、さらに記録可能な一層となる。

## 用例

> 薄い本疑惑が発生する。  
> → 否認する。  
> → 「否認した」と記録する。  
> → その記録が、次の観測対象になる。  
> → 「この予測発言も、いずれ記録される」と予測する。  
> → その予測発言を実際に記録する。  
> → ここまでの連鎖を、メタリョーシカ構造として観測する。

この例では、最初の疑惑だけが対象なのではない。否認、否認の記録、記録されることの予測、予測発言の記録、そして構造そのものの観測が、順次外側の層を形成している。

## 派生語

### メタリョーシカ化

ある言説・会話・出来事などが、自己言及的な観測と記録を繰り返し、メタリョーシカ構造を形成してゆくこと。

> その一言を説明し始めた時点で、議論がメタリョーシカ化した。

### メタリョーシカ的

メタな層が後から外側へ累積してゆく性質を持つさま。

> このやり取りは、かなりメタリョーシカ的だ。

### メタリョーシカ構造

観測・評価・記録・予測が、それぞれ次の観測対象を生み出し、自己言及的な層が連続的に付加される構造。

## 語誌

**メタ**（meta-、ある対象を一段上の視点から扱うこと）と、**マトリョーシカ**（内側に同型の人形を収める入れ子人形）を組み合わせた造語。

ただし、両者の対応は単なる「入れ子」の比喩にとどまらない。マトリョーシカが内側へ向かう固定的な入れ子であるのに対し、メタリョーシカは、観測と記録の反復によって外側へ動的に層が増える。
